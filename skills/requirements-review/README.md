# Requirements Review Skill

AI-skill для автоматичного рев'ю вимог **перед** початком тест-аналізу.

## Навіщо цей skill

Слабкі, неоднозначні або неповні вимоги — одна з найчастіших причин багів, 
пропущених тест-кейсів і переробок на пізніх етапах. Цей skill дозволяє 
AI-агенту (Claude Code, Cursor тощо) автоматично перевіряти вимогу на 
якість ще до того, як тестувальник почне писати тест-кейси.

## Що перевіряє

Skill оцінює вимогу за **7 критеріями якості**:

| Критерій | Що перевіряється |
|---|---|
| Атомарність | Вимога описує одну дію/умову, а не декілька одразу |
| Однозначність | Формулювання не допускає різних трактувань |
| Повнота | Немає прогалин — усі умови й винятки описані |
| Несуперечність | Вимога не суперечить іншим вимогам |
| Неповторюваність | Вимога не дублює вже наявну |
| Тестованість | За вимогою можна написати перевірювані тест-кейси |
| Реалізовність | Вимогу технічно можливо реалізувати |

## Коли спрацьовує

Агент застосовує skill автоматично, коли:
- користувач просить перевірити вимогу або зробити рев'ю вимог
- запитує "чи готова ця вимога до тестування", "чи можна писати тест-кейси за цим"
- надає текст вимоги / user story / acceptance criteria без явного запиту, 
  але контекст натякає на перевірку якості перед тест-аналізом

## Приклад використання

**Вхідні дані:**
> Система повинна швидко обробляти дані користувача.

**Результат рев'ю:** skill виявить порушення критеріїв *однозначність* 
(що означає "швидко"?) та *тестованість* (немає вимірюваного критерію 
успіху) і запропонує уточнений варіант формулювання.
